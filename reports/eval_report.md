## 结论

⚠️ **主指标已饱和，但那是假象，不要据此认为微调没效果。**

格式遵循率 99.0% → 100.0%（+1.0 pp），看似没差别。但这个指标带容错提取兜底：基座 300 条里有 **266 条**是靠剥代码块、截花括号才达标的，真正自己就输出干净 JSON 的只有 10.3%；微调后裸 JSON 率是 100.0%。

真实结论：**微调把「靠后处理救回来」变成了「本来就合法」（裸 JSON 率 +89.7 pp）。** 这个增益比主指标更有实际意义——生产环境不该指望下游系统必须做容错提取，那本身就是不稳定的来源。

内容层面，审核结论准确率从 54.7% 变为 79.0%，问题类型 F1 从 0.000 变为 0.830。

注意：格式遵循率与内容准确率是两件事。格式达标只说明输出结构可用，不代表审核判断正确——后者需要真实标注数据才能可靠评估，而本项目的标签是合成规则生成的。
